# 第 15 章　正则化（Regularization）

> 译自 Nathan Lambert, *Reinforcement Learning from Human Feedback*（rlhfbook.com），2026-07-01 版，原文第 175–183 页。

在本书中，我们已经学到许多修改模型的工具，让模型能从人类偏好、可验证奖励（verifiable rewards）以及其他有价值的信号中学习。我们使用的所有方法都非常强大，可能导致模型相对于前一个训练阶段那个强大、通用的模型（通常称为参考模型（reference model））改变过多。当模型从某个给定的奖励中学得太多，造成分布外（out-of-distribution）表现下降时，这就称为「过度优化」（over-optimization）（如前一章所讨论）。

在整个 RLHF 优化过程中，会使用许多正则化步骤来防止对奖励模型的过度优化。在这些情境中，过度优化看起来就像是输出无意义文字的模型。一些优化「脱轨」的例子包括：模型输出看似可依循的数学推理、答案却错得离谱，或是重复文字、切换语言、出现过多特殊字符。本章涵盖用来控制模型优化的各种方法。

截至 2026 年，大多数 RLHF 实现所采用的最流行变体，是在生成样本上计算从目前策略到参考策略的 KL 距离（KL distance）。「KL 距离」是在训练过程中表达*优化距离*（optimization distance）的口语说法，尽管 KL 散度（KL divergence）——用来衡量两个概率分布之间差异的底层数学方法——并不满足真正距离度量（distance metric）所需的形式性质（把这个数字称为距离，只是比称它为分布差异的数值度量来得方便）。许多其他正则化技术曾在文献中出现，随后又在该研究路线的下一次模型迭代中消失。也就是说，核心的生成 KL 距离之外的正则化，通常是用来稳定实验设定，而这些设定在下一代往往可以被简化。尽管如此，理解在 RLHF 中约束优化的工具仍然很重要。

*本章中，我们用 $x$ 表示提示（prompt）、$y$ 表示补全（completion）。这种记号在语言模型文献中很常见，因为这些方法是作用于完整的提示–补全对，而非个别词元（token）。*

在具有奖励模型 $r_\theta$ 的 RLHF 框架中使用时，一般形式如下：

$$r = r_\theta - \lambda r_{\text{reg.}} \tag{138}$$

其参考实现为：

$$r = r_\theta - \lambda_{\text{KL}} \mathcal{D}_{\text{KL}} \left( \pi_{\text{RL}}(y \mid x) \,\|\, \pi_{\text{ref}}(y \mid x) \right) \tag{139}$$

## 15.1 RL 优化中的 KL 散度（KL Divergence in RL Optimization）

数学定义请参见附录 A「定义」。KL 散度衡量的是一个概率分布偏离另一个分布的程度——当 KL 为零时，两个分布会产生完全相同的输出。回顾其定义如下：

$$\mathcal{D}_{\text{KL}}(P\|Q) = \sum_{x \in \mathcal{X}} P(x) \log\left(\frac{P(x)}{Q(x)}\right) \tag{140}$$

在 RLHF 中，我们关心的两个分布通常是新模型版本的分布（例如 $P(x)$）与参考策略的分布（例如 $Q(x)$）。不同的优化器会使用不同的 KL 方向。本书通篇使用的最常见「KL 惩罚」（KL Penalty），称为对参考策略的反向 KL（reverse KL）。实际应用中，这可以简化为一个蒙地卡罗估计（Monte Carlo estimate）：从 RL 模型采样词元，再由参考模型计算其概率。直观来说，这种反向 KL 具有一个数值性质：当新模型 $P$（或 $\pi_{\text{RL}}$）将大量概率质量放在原始参考模型指派低概率的区域时，就会施加很大的惩罚。

另一个 KL 方向在机器学习中仍然常被使用，例如某些 RL 算法内部的信赖区域（trust region）计算。这种惩罚直观上惩罚的是：新模型的更新*没有*将概率指派给 $Q$（或 $\pi_{\text{ref}}$）中的高概度（high-likelihood）区域。这更接近于蒸馏（distillation）或行为复制（behavioral cloning）所使用的目标。

### 15.1.1 参考模型到生成内容（Reference Model to Generations）

KL 惩罚最常见的实现方式，是比较训练期间生成的词元与一个静态参考模型之间的距离。其直觉是：你所训练的出发模型具有一种你希望保持接近的风格。这个参考模型通常是指令微调（instruction tuned）模型，但也可以是先前的 RL 检查点（checkpoint）。透过简单的代换，我们采样的模型就变成 $\pi_{\text{RL}}(x)$ 与 $\pi_{\text{ref}}(x)$，如上方公式 139 所示（在标准定义中通常写作 $P$ 与 $Q$，套用于 RL 的 KL 惩罚时）。这样的 KL 散度惩罚早在大型语言模型流行之前，就已被应用于对话智能体（dialogue agents）[354]，而 KL 控制也很快确立为微调预训练模型的核心技术 [355]。

### 15.1.2 实现范例（Implementation Example）

实际应用中，KL 散度的实现经常采用近似 [126]，使实现简单许多。根据上述定义，当直接从分布 $P$ 采样时，KL 的加总可以转换为期望值（这里的 $x$ 是样本空间上的一般随机变量，而非本书其他地方使用的提示记号）。在这种情况下，$P$ 是目前正在训练之模型的生成分布（也就是说，不是参考模型）。此时，KL 散度的计算改为如下：

$$\mathcal{D}_{\text{KL}}(P \,\|\, Q) = \mathbb{E}_{x \sim P} \left[ \log P(x) - \log Q(x) \right]. \tag{141}$$

这种基于样本的形式在实现上简单得多，特别是在直接处理语言模型训练中频繁使用的对数概率（log probabilities）时。

```python
# 步骤 1：generate() 以自回归方式逐词元采样出完整序列
generated_tokens = model.generate(inputs)

# 步骤 2：forward() 对序列做单次前向传递，取得逐词元 logits（不采样）
logits       = model.forward(generated_tokens[:, :-1]).logits
ref_logits   = ref_model.forward(generated_tokens[:, :-1]).logits

# 步骤 3：将 logits 转为对数概率
logprobs     = F.log_softmax(logits, dim=-1)
ref_logprobs = F.log_softmax(ref_logits, dim=-1)

# 步骤 4：提取每个模型指派给实际生成之词元的概率
token_logprobs     = logprobs.gather(-1, generated_tokens[:, 1:].unsqueeze(-1)).squeeze(-1)
ref_token_logprobs = ref_logprobs.gather(-1, generated_tokens[:, 1:].unsqueeze(-1)).squeeze(-1)

# 步骤 5：加总得到序列层级的对数概率；其差值即为 KL 的近似
seq_logprob     = token_logprobs.sum(dim=-1)
ref_seq_logprob = ref_token_logprobs.sum(dim=-1)

kl_approx = seq_logprob - ref_seq_logprob
kl_full   = F.kl_div(ref_logprobs, logprobs, reduction='batchmean')
```

一些实现范例包括 TRL 以及 Hamish Ivison 的 Jax 代码。

## 15.2 隐式正则化（Implicit Regularization）

本章其他小节描述的是*显式*（explicit）正则化：KL 惩罚、预训练梯度（pretraining gradients）与间距损失（margin losses），这些都是实践工作者刻意加入训练目标的项目。愈来愈多的实证研究显示，基于 RL 的后训练（post-training）也提供了*隐式*（implicit）正则化——一种对记忆化（memorization）与灾难性遗忘（catastrophic forgetting）的内置抵抗力，源自 on-policy 优化本身的结构。这是损失更新的本质使然，即使不使用任何用来控制 RL 训练的显式工具（例如 KL 惩罚或重播缓冲区（replay buffers））也是如此。

### 15.2.1 SFT 记忆、RL 泛化（SFT Memorizes, RL Generalizes）

后训练社群一直面临一个核心问题：在单一任务上训练时，模型学到的是可以迁移到未见变体的可泛化规则，还是记住了训练分布的表面模式？Chu et al. 2025 [9] 以一项受控实证研究回答了这个问题，直接分离出后训练方法——SFT 对上 RL——对分布外（out-of-distribution, OOD）泛化的影响。答案十分明确：RL 学到可迁移的规则，而 SFT 记忆训练数据，并在分布偏移下崩溃。

该研究使用两个内置规则变化的环境来理解其中的权衡：

- **GeneralPoints** 是一个算术纸牌游戏：模型收到四张扑克牌，必须以运算符（+、-、*、/）组合牌面数值，以达到目标数字（默认为 24）。OOD 测试改变的是花牌的计分方式：训练时使用一种规则（J、Q、K 都算 10），评估时使用另一种（J = 11、Q = 12、K = 13）。
- **V-IRL** 是一个真实世界的视觉导航任务：模型依循语言指令穿越城市街道路线，并沿途辨识地标。OOD 偏移是将动作空间从绝对方向（北、东）改为相对方向（左、右）。

在所有任务变体中，随着训练计算量扩大，RL 持续改善 OOD 表现，而 SFT 尽管改善了分布内（in-distribution）表现，却持续*劣化* OOD 表现。差异幅度十分惊人：在仅有语言输入的 V-IRL 上，OOD 偏移是从绝对方向座标改为相对方向座标，RL 将 OOD 逐步准确率从 80.8% 提升到 91.8%，而 SFT 却使其从 80.8% 崩溃到 1.3%。SFT 模型不只是未能泛化：它摧毁了基础模型原本就具备的空间推理能力，退化成一张从指令词组对应到绝对方向的查找表。

### 15.2.2 以做促记：On-Policy 数据减缓遗忘（Retaining by Doing: On-Policy Data Mitigates Forgetting）

上一节显示，在单一任务上 RL 能泛化、而 SFT 会记忆。Chen et al. 2025 [356] 则提出互补的问题：当*依序*（sequentially）在多个任务上训练时，模型能否保留它原本已经知道的东西？他们发现，RL 在目标任务上取得与 SFT 相当或更高的增益，同时遗忘的程度远低于 SFT，并将这项优势追溯至两个目标函数在优化内容上的根本差异。

要理解这两种方法的行为为何如此不同，我们可以透过 KL 散度的视角来查看它们的目标。在本节中，我们首先说明两种常见的后训练方法可以对应到 KL 散度的两个方向，然后解释将它们作为损失函数使用时的数值行为，如何转化为不同的模型行为。

KL 散度定义为两个分布之间对数比值的期望，$\mathbb{E}_{x\sim P}\left[\log \frac{P(x)}{Q(x)}\right]$，可以写成对数差的形式，且有两个方向：

- **前向 KL（Forward KL）**：$\text{KL}(P\|Q) = \mathbb{E}_{x\sim P}[\log P(x) - \log Q(x)]$
- **反向 KL（Reverse KL）**：$\text{KL}(Q\|P) = \mathbb{E}_{x\sim Q}[\log Q(x) - \log P(x)]$

其中 $P$ 是目标分布，$Q$ 是我们以参数 $\theta$ 建模的分布。关键差异在于我们从哪个分布采样：前向 KL 从目标（或最佳）分布 $P$ 采样，而反向 KL 从我们的策略 $Q$ 采样。在下面的推导中，$P$ 对应到目标 $\pi_\star$（分析 SFT 时是训练数据分布，分析 RL 时是奖励最佳策略（reward-optimal policy）），$Q$ 则对应到所学的策略 $\pi_\theta$（我们正在训练的对象）。SFT 把目标放在前面——$\text{KL}(\pi_\star\|\pi_\theta)$——而 RL 颠倒了顺序——$\text{KL}(\pi_\theta\|\pi_\star)$——改变了我们采样的分布。样本提供了学习所需的数据，而目标函数（SFT 或 RL）则依据这些数据形塑模型。

#### 15.2.2.1 SFT 前向 KL（SFT Forward KL）

从前向 KL 的定义开始：

$$\text{KL}(\pi_\star \| \pi_\theta) = \mathbb{E}_{(x,y)\sim\mathcal{D}} \left[ \log \pi_\star(y \mid x) - \log \pi_\theta(y \mid x) \right]$$

将对数差上的期望拆成两项，得到：

$$= \mathbb{E}_{(x,y)\sim\mathcal{D}} \left[ \log \pi_\star(y \mid x) \right] - \mathbb{E}_{(x,y)\sim\mathcal{D}} \left[ \log \pi_\theta(y \mid x) \right]$$

第一项 $\mathbb{E}[\log \pi_\star(y \mid x)]$ 只依赖于数据分布，等于负熵 $-H(\pi_\star)$——一个不随 $\theta$ 改变的常数。第二项 $-\mathbb{E}[\log \pi_\theta(y \mid x)]$ 是数据集上的负对数概度（negative log-likelihood），也就是标准的 SFT 交叉熵损失 $\mathcal{L}_{\text{SFT}}(\theta)$。代入后得到：

$$= \underbrace{-H(\pi_\star)}_{\text{const}} + \mathcal{L}_{\text{SFT}}(\theta) \propto \mathcal{L}_{\text{SFT}}(\theta) \tag{142}$$

由于熵项相对于 $\theta$ 是常数，这两个损失具有相同的梯度与相同的最小值——最小化 SFT 损失等价于最小化**前向 KL** 散度 $\text{KL}(\pi_\star\|\pi_\theta)$。

#### 15.2.2.2 RL 反向 KL（RL Reverse KL）

让我们从标准的 KL 正则化 RL 目标开始：

$$\max_\pi \; \mathcal{J}_{\text{RL}}(\theta) = \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi(\cdot \mid x)} \left[ r(x,y) \right] - \beta \cdot \text{KL}(\pi(\cdot \mid x) \| \pi_{\text{ref}}(\cdot \mid x)) \tag{143}$$

提出 $-\beta$ 可将最大化转为最小化：

$$= \min_\pi \; \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi(\cdot \mid x)} \left[ \log \frac{\pi(y \mid x)}{\pi_{\text{ref}}(y \mid x)} - \frac{1}{\beta} r(x,y) \right] \tag{144}$$

引入配分函数（partition function）$Z(x) = \sum_y \pi_{\text{ref}}(y \mid x)\exp\left(\frac{1}{\beta}r(x,y)\right)$，将经奖励倾斜（reward-tilted）的参考分布归一化为有效的概率分布，并加减 $\log Z(x)$ 之后，内层期望便成为一个 KL 散度：

$$= \min_\pi \; \mathbb{E}_{x\sim\mathcal{D}} \left[ \text{KL}\left( \pi(\cdot \mid x) \,\Big\|\, \frac{1}{Z(x)}\pi_{\text{ref}}(\cdot \mid x)\exp\left(\frac{1}{\beta}r(x,y)\right) \right) - \log Z(x) \right] \tag{145}$$

由于 $\log Z(x)$ 不依赖于 $\pi$，而 KL 散度非负、且唯有两个分布完全相同时才等于零，因此当 $\pi$ 等于这个奖励倾斜分布时，KL 便在零处取得最小值。于是，在奖励 $r(x,y)$ 之下的最佳策略为：

$$\pi_\star(y \mid x) = \frac{1}{Z(x)} \pi_{\text{ref}}(y \mid x) \exp\left(\frac{1}{\beta} r(x,y)\right) \tag{146}$$

现在我们可以直接展示它与反向 KL 的关联。展开 $\text{KL}(\pi_\theta\|\pi_\star)$，并代入 $\log \pi_\star(y \mid x) = \log \pi_{\text{ref}}(y \mid x) - \log Z(x) + \frac{1}{\beta}r(x,y)$：

$$
\begin{aligned}
\text{KL}(\pi_\theta \| \pi_\star) &= \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi_\theta(\cdot\mid x)} \left[ \log \pi_\theta(y \mid x) - \log \pi_\star(y \mid x) \right] \\
&= \mathbb{E}_{x\sim\mathcal{D},\, y\sim\pi_\theta(\cdot\mid x)} \left[ \log \pi_\theta(y \mid x) - \log \pi_{\text{ref}}(y \mid x) + \log Z(x) - \frac{1}{\beta} r(x,y) \right] \\
&= -\frac{1}{\beta}\mathbb{E}_{x,y}[r(x,y)] + \text{KL}(\pi_\theta(\cdot \mid x) \,\|\, \pi_{\text{ref}}(\cdot \mid x)) + \underbrace{\log Z(x)}_{\text{const}} \\
&\propto -\frac{1}{\beta}\mathbb{E}_{x,y}[r(x,y)] + \text{KL}(\pi_\theta(\cdot \mid x) \,\|\, \pi_{\text{ref}}(\cdot \mid x)) \\
&= -\frac{1}{\beta}\mathcal{J}_{\text{RL}}(\theta)
\end{aligned}
$$

等价地，最大化 RL 目标 $\mathcal{J}_{\text{RL}}(\theta)$ 就等同于最小化**反向 KL** 散度 $\text{KL}(\pi_\theta\|\pi_\star)$。

这个推导显示，SFT 与 RL 优化的是根本不同的目标：SFT 最小化前向 KL，RL 最小化反向 KL。

KL 散度的两个方向会引发不同的优化压力。

前向 KL 会在目标分布有质量而模型没有的地方惩罚模型，因此倾向鼓励**模式涵盖**（mode covering）——模型将概率广泛分散，以涵盖目标的所有主要模式。原因在于：前向 KL 的期望是在 $\pi_\star$ 之下取的，所以模型若未能对目标具有质量的区域指派概率，就会受到重罚。

反向 KL 只会在模型实际放置质量的区域惩罚模型，因此倾向鼓励**模式寻求**（mode seeking）：模型可以集中在单一高概率模式上而忽略其他模式。这里的期望是在 $\pi_\theta$——模型自身的分布——之下取的，因此 $\pi_\theta(y \mid x) \approx 0$ 的区域对损失的贡献微乎其微，即使 $\pi_\star$ 在那里指派了可观的质量。同时，它也会惩罚模型把质量放在目标没有质量的地方。

基于这个区别，我们可能会天真地预期 SFT 遗忘得比 RL *少*：模式涵盖的前向 KL 应该会在目标的所有模式上维持质量、保留旧知识，而模式寻求的反向 KL 则可能塌缩到单一高奖励模式并抛弃其他模式。然而，事实正好相反。这种直觉假设的是单峰（unimodal）策略，但预训练的大型语言模型包含多个模式——对于多峰（multimodal）分布，这个动态会翻转。

考虑一个具有两个模式的策略：一个代表先验知识的「旧」模式，以及一个对应目标任务的「新」模式（图 43）。前向 KL（SFT）试图涵盖目标分布的两个模式，这迫使策略拉伸，并*从*旧模式重新分配概率质量，破坏其形状并造成遗忘。相较之下，反向 KL（RL）只需要在某个高奖励区域放置质量，因此它可以将自己采样到的新模式朝目标移动，完全不触碰旧模式，让先验知识保持完好。

RL 的模式寻求行为——反向 KL 的一种结构性性质——保留了模型先验知识的广度，并带来更好的泛化。

总结如下：

- **SFT（前向 KL）**：$\text{KL}(\pi_\star\|\pi_\theta)$——样本来自目标 $\pi_\star$，一个由人类撰写的补全所构成的固定数据集。对每个范例，我们问：我们的模型 $\pi_\theta$ 对它指派了多少概率？模型从不生成任何东西；它学习模仿。这种模式涵盖的压力迫使策略广泛地重新分配概率质量，可能因此破坏先验知识。
- **RL（反向 KL）**：$\text{KL}(\pi_\theta\|\pi_\star)$——样本来自我们自己的策略 $\pi_\theta$。对模型生成的每个补全，我们问：它与奖励最佳策略 $\pi_\star$ 有多接近？由于模型只在自己的生成内容上训练，更新会停留在它原本就放置概率质量的局部区域——奖励信号告诉它应该强化其中哪些生成内容，将概率朝 $\pi_\star$ 移动，而不干扰分布的其余部分。

### 15.2.3 RL 的剃刀：为何在线 RL 遗忘得更少（RL's Razor: Why Online RL Forgets Less）

上一节显示，on-policy 采样驱动了 RL 对遗忘的抵抗力，并将其机制追溯到前向对反向 KL 的动态。对任何给定的任务而言，存在许多能达成高表现的不同策略。Shenfeld et al. 2026 [357] 对 RL 的泛化提出了互补的观点，提出 **RL 的剃刀**（RL's Razor）论题，其主张如下：

> 在新任务的众多高奖励解之中，RL 等 on-policy 方法天生偏向那些在 KL 散度上与原始策略保持较近的解。

作者发现，对过去任务的遗忘程度，与微调后策略偏离初始模型的距离（以 KL 散度衡量）成正比：

$$\text{Forgetting} \approx f\left( \mathbb{E}_{x\sim\tau} \left[ \text{KL}(\pi_0(\cdot \mid x) \| \pi(\cdot \mid x)) \right] \right) \tag{147}$$

在多种 RL 与 SFT 的训练变体中，作者以实证方式证明，遗忘与训练后策略和初始策略之间的 KL 散度高度相关（$R^2 = 0.96$），**而且是以新任务数据衡量的**。这一点令人惊讶，因为 KL 是在*新任务的*输入分布上衡量的，而不是在先前任务的保留数据上，但它仍然能够预测过去任务的表现下降。在实际应用中，这为我们提供了一个强大的工具，可以直接从基础策略与训练后策略之间的漂移来估计遗忘——在我们新的专门数据上衡量 KL 距离。

为了厘清是什么驱动了 RL 策略较小的 KL 偏移，作者沿着两个轴分解 RL 与 SFT 的差异——on-policy 对上离线（offline）数据，以及目标函数是否包含负梯度（negative gradients）（RL 中存在：当样本得分低于奖励基线时；SFT 中则不存在：它只强化正确的示范），负梯度会将概率从错误的输出推开。值得注意的是，他们发现 on-policy 对上离线数据完全解释了泛化表现的差异，而负梯度没有可辨别的影响。

直观而言，on-policy 方法采样的是模型原本就指派了不可忽略概率的输出，因此每次更新都被约束在接近目前分布的范围内。另一方面，SFT 是在一个固定的外部分布上训练，该分布可能与模型目前产出的内容相距任意远，而每一步梯度都会将模型拉向那个遥远的目标，无视模型自身的信念。

## 15.3 其他类型的正则化（Other Types of Regularization）

在后训练文献中，许多知名模型纳入了其他的正则化方法，协助它们在各自的设定中达到领先的表现。这里收录以下两个例子，是为了描绘一些领先模型如何操纵后训练设定以获得稳定的优化，而不是把它们当作在每种设定中都必然有效的工具。无数更有创意的解法可以奏效，也将会被发现！

### 15.3.1 预训练梯度（Pretraining Gradients）

看待正则化的另一种方式是：你可能有一个希望模型保持接近的*数据集*，如同 InstructGPT [3] 所做的那样，「为了修复在公开 NLP 数据集上的性能退化」。为了实现这一点，他们修改了 RLHF 的训练目标。以公式 138 为出发点，我们可以将其转换为一个透过从 RL 策略模型采样来优化的目标函数——补全 $y$ 来自 RLHF 所用之 RL 数据集中的提示 $x$——得到：

$$J(\theta) = \mathbb{E}_{(x,y)\sim\mathcal{D}_{\pi_{\text{RL},\theta}}} \left[ r_\theta(y \mid x) - \lambda r_{\text{reg.}} \right] \tag{148}$$

接着，我们可以在预训练期间使用的标准自回归下一词元预测损失（next-token prediction loss）之上，针对从预训练语料库（或其他数据集）采样的一组文件，加入一个鼓励较高概率的额外奖励，以维持文字的连贯性：

$$J(\theta) = \mathbb{E}_{(x,y)\sim\mathcal{D}_{\pi_{\text{RL},\theta}}} \left[ r_\theta(y \mid x) - \lambda r_{\text{reg.}} \right] + \gamma \mathbb{E}_{x\sim\mathcal{D}_{\text{pretrain}}} \left[ \log(\pi_{\text{RL},\theta}(x)) \right] \tag{149}$$

近期研究提出使用负对数概度项来平衡直接偏好优化（Direct Preference Optimization, DPO）的优化 [358]。鉴于 DPO 损失的成对（pairwise）性质，同样的损失修改也可以套用在奖励模型训练上，约束模型去预测准确的文字。

该优化是对 DPO 的一项修改。

$$\mathcal{L}_{\text{DPO+NLL}} = \mathcal{L}_{\text{DPO}}(c_i^w, y_i^w, c_i^l, y_i^l \mid x_i) + \alpha \mathcal{L}_{\text{NLL}}(c_i^w, y_i^w \mid x_i) \tag{150}$$

$$= -\log \sigma \left( \beta \log \frac{P_\theta(c_i^w, y_i^w \mid x_i)}{P_{\text{ref.}}(c_i^w, y_i^w \mid x_i)} - \beta \log \frac{P_\theta(c_i^l, y_i^l \mid x_i)}{P_{\text{ref.}}(c_i^l, y_i^l \mid x_i)} \right) - \alpha \frac{\log P_\theta(c_i^w, y_i^w \mid x_i)}{|c_i^w| + |y_i^w|}, \tag{151}$$

其中 $P_\theta$ 是可训练的策略模型，$P_{\text{ref.}}$ 是固定的参考模型（通常是 SFT 检查点），而 $(c_i^w, y_i^w)$ 与 $(c_i^l, y_i^l)$ 分别表示提示 $x_i$ 所对应的获胜与落败补全。第一项是标准的 DPO 逻辑斯损失（logistic loss）：它利用对数概度比之差 $\log \frac{P_\theta}{P_{\text{ref.}}}$ 来扩大胜、负之间的间距（margin），而 $\beta$ 控制这个偏好信号将模型拉离参考模型的强度。第二项是对获胜补全施加的长度归一化（length-normalized）负对数概度惩罚，以 $\alpha$ 加权，有助于让偏好文字在绝对的语言建模意义上维持高概度，而不仅仅是相对于被拒绝的样本更好而已。

### 15.3.2 基于间距的正则化（Margin-Based Regularization）

在 RLHF 技术堆栈的其他部分，对优化的控制较不明确。大多数奖励模型除了标准的对比损失函数（contrastive loss function）之外，没有任何正则化。直接对齐算法（Direct Alignment Algorithms）则以不同的方式处理对 KL 散度的正则化——透过 $\beta$ 参数（见直接对齐一章）。

Llama 2 为奖励模型训练提出了一种间距损失（margin loss）[49]：

$$\mathcal{L}(\theta) = -\log\left( \sigma\left( r_\theta(y_c \mid x) - r_\theta(y_r \mid x) - m(y_c, y_r) \right) \right) \tag{152}$$

其中 $m(y_c, y_r)$ 是两个数据点 $y_c$ 与 $y_r$ 之间的间距，代表两位标注者评分之差的数值大小。这可以透过让标注者以数值量表对输出评分，或使用量化的排序方法（例如李克特量表（Likert scales））来达成。

奖励间距在直接对齐文献中被大量使用，例如奖励加权 DPO（Reward-weighted DPO）；奖励感知偏好优化（Reward-aware Preference Optimization, RPO），它遵循 DPO 损失的形式，将奖励模型分数集成进更新规则 [30]；以及 REBEL [190]，它在回归损失（regression-loss）的形式中带有奖励差值加权。
